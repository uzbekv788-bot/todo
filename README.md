# PlayZone — магазин игр для PS5

Демонстрационный сайт магазина цифровых ключей для PlayStation 5. Чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. Или поднимите локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Что есть

- **Подборка** — три игры в фокусе с переключением.
- **Каталог** — 30 игр с обложками, поиском, фильтром по жанрам и сортировкой. По клику на обложку открывается окно с разработчиком и сюжетом.
- **Оплата** — состав заказа и форма: e-mail, телефон, способ оплаты (карта или СБП), номер карты с определением платёжной системы и проверкой контрольной цифры, срок действия, CVC, имя на карте.
- **Вопросы** — ответы на частые вопросы.
- Светлая и тёмная тема: по умолчанию как в системе, выбор запоминается.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка страницы |
| `styles.css` | Стили, цветовые токены обеих тем |
| `data.js` | Каталог: названия, цены, жанры, разработчики, сюжеты |
| `script.js` | Каталог, корзина, форма оплаты, переключение темы |
| `covers/` | Обложки игр (`cover-<id>.jpg`) |

## Важно

- Оплата ненастоящая: данные карты проверяются только в браузере, никуда не отправляются и не сохраняются. Для проверки подходит тестовая карта `4242 4242 4242 4242`.
- Цены — базовые цены PlayStation Store (США) без скидок на момент создания и могут устареть.
- Названия игр и обложки принадлежат их правообладателям. Обложки взяты из статей английской Википедии и используются здесь только для демонстрации.
